# NovaPS5 v0.1.1

Paste this body into the GitHub release, then attach `NovaPS5-Setup-0.1.1.exe`, `latest.yml` and
`NovaPS5-Setup-0.1.1.exe.blockmap` from `release/`.

---

## What's new

- **Copy anything you read.** Text is selectable throughout the app — install verdicts, error details,
  file paths, release notes and log lines. Use `Ctrl+C`, `Ctrl+A`, or right-click for a Copy / Select all
  menu.
- **A cleaner sidebar.** The panel now opens straight into **Library** and **Settings**; the redundant
  brand block was removed.
- **Credits and license, done properly.** NovaPS5 is licensed **GPL-2.0-or-later**, because it
  redistributes engine tooling from [AnyPS5](https://github.com/boykopovar/AnyPS5) (also GPL-2.0). The
  conversion engine is AnyPS5 by [@boykopovar](https://github.com/boykopovar) — **the real work is
  theirs**; NovaPS5 is the library, converter and launcher around it. The full license text ships in
  the app and in this repository.

### Fixed

1. Menus now include the standard **Edit** roles, so cut/copy/paste/undo actually work with their
   Windows shortcuts.
2. Right-clicking inside the window no longer does nothing — you get the expected text menu.

---

Requires Windows 10/11 (x64). Python and the conversion runtime are bundled; the app installs per-user
with no admin prompt.
