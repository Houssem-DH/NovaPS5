# NovaPS5 v0.1.3

Paste this body into the GitHub release, then attach `NovaPS5-Setup-0.1.3.exe`, `latest.yml` and
`NovaPS5-Setup-0.1.3.exe.blockmap` from `release/`.

---

## Highlights

- **A crash that hit games right after launch is fixed.** Some titles walk their trophy list by asking
  the runtime for trophy `0`, `1`, `2`, … and stop when it reports the invalid trophy id. On a PS5 that
  call returns `0x8055390A` (`SCE_NP_TROPHY2_ERROR_INVALID_TROPHY_ID`); AnyPS5 0.1.3 instead throws an
  uncaught `std::invalid_argument` for an id the game's own trophy package does not define, and the
  process aborts about a second in (`0xC0000409` in `ucrtbase.dll`). Hollow Knight: Voidheart Edition
  is one of these games: its package defines 35 trophies (`0000`–`0034`) and it probes `35`.

  The new **Compatibility** panel offers **Compatibility placeholders**: NovaPS5 renames the game's
  `.ucp` trophy package to `.ucp.disabled` (the file stays on disk, revocation is one click), and the
  runtime's own fallback answers trophy requests with placeholder data and success, so the game keeps
  running. New installs that hit this abort during the post-install launch test are retried once
  automatically and the mode is saved with the game. The trade-off is stated in the panel: trophy
  names, descriptions and the platinum rule are unavailable until you switch back to **Game's package**.

- **The store is now the Games catalog — with no prices.** Browsing, searching, region and genre
  filters, the wishlist and downloads all stay, but every price, currency label and buy button is gone.
  NovaPS5 never sells anything; it points at the catalog and at your own archives.

- **Graphics & launch settings that map to real switches.** Every installed game gets a panel that is
  saved per game and applied before the process starts: VSync / present mode (`ANYPS5_PRESENT_MODE`),
  Vulkan GPU (`ANYPS5_GPU`), the performance overlay and its corner (`ANYPS5_OVERLAY`,
  `ANYPS5_OVERLAY_POS`), shader cache (`ANYPS5_NO_SHADER_CACHE`), GPU and driver timing
  (`APS5_PROFILE_GPU`, `APS5_PROFILE_DRAW`) and session telemetry. No invented resolution, upscaler or
  FPS-unlock controls — the runtime has none, so the app does not pretend otherwise.

- **A session monitor that explains the frame-rate ceiling instead of hiding it.** Live FPS, average,
  1% low and frame time from AnyPS5's own telemetry, plus a read-only view of the display refresh rate.
  When a game stays near 60 FPS the panel says why: AnyPS5 paces flips at 59.94 Hz unless the title
  requests its 119.88 Hz output mode, which needs both a 120 Hz-or-faster display and the `0x40` bit in
  the game's `param.json` `attribute3`. It also links straight to **Windows display settings**, so the
  one part the app cannot change for you is one click away.

## Fixes

1. **Shim folders no longer break installs.** `fakelib` / `fake_lib` / `fake-libs` folders ship stand-in
   copies of console libraries. Relinking them produced modules that shadowed the runtime's own and
   made converted games abort on unresolved imports. They are now reported in the install report and
   never converted.
2. **Clearer install verdicts.** Unresolved ELF imports are aggregated into one line with the importing
   modules and providers, Windows error 127 ("function not found") gets its own explanation, and a CPU
   report of `lacks none` is no longer read as a missing feature.
3. **Present mode is no longer silently downgraded.** Turning VSync off kept `mailbox` /
   `fifo_latest_ready` selected while actually presenting `fifo`; the value you pick is the value the
   runtime gets.
4. **Trophy aborts are reported as trophy aborts.** The launch test now quotes the trophy id and package
   name instead of a bare `0xC0000409`, and points at the fix.
5. **Re-installs keep your settings.** Graphics, compatibility and play history survive a re-install.
6. **Telemetry hygiene.** Session folders are retained with a cap instead of growing forever, and the
   tail parser no longer mis-reads a line that straddles a buffer boundary.
7. **Older preload scripts are caught.** A renderer running against a stale preload now gets a clear
   "restart the app" message instead of `window.api.setGameGraphics is not a function`.

---

Requires Windows 10/11 (x64). Python and the conversion runtime are bundled; the app installs per-user
with no admin prompt.

**Updating:** NovaPS5 v0.1.0–v0.1.2 will download this release in the background and hold it until you
press **Restart to update**. Your library and settings are untouched.
