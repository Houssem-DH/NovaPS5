# NovaPS5 v0.1.0

The first release of **NovaPS5** by Nova Crafted — a Windows library that installs, converts and
launches PS5 game dumps with the [AnyPS5](https://github.com/boykopovar/AnyPS5) relinker.

Paste this body into the GitHub release (it is Markdown, so the app renders it in its
**What's new** dialog), then attach `NovaPS5-Setup-0.1.0.exe`, `latest.yml` and
`NovaPS5-Setup-0.1.0.exe.blockmap` from `release/`.

---

## Highlights

- **Every dump installs.** Duplicate modules, `sce_module/` **and** `sce_modules/`, leftover `*.bak*`
  files, odd archive entries and `.rar` / `.7z` sources are handled automatically.
- **Preflight before install.** The eboot is trial-unwrapped first, so encrypted or truncated dumps are
  flagged with a plain reason *before* anything is copied.
- **Works / Not working verdict.** Each install ends with a real launch test, watched for 10 seconds
  with a crash log — `✓ Works` or `✗ Not working` with the exit code explained.
- **Nothing to install by hand.** Python and the conversion runtime ship with the app; the runtime is
  refreshed from the AnyPS5 releases.

### New in this release

1. Nova Crafted visual identity across the app, exe and installer
2. Frameless window with a tray-friendly close button
3. **Self-update:** NovaPS5 checks this repository on every launch, downloads a newer release in the
   background, installs it and restarts into it — then shows these notes
4. Library scan, custom games folder with safe relocation, and per-game detail view

> Conversion always runs locally: nothing is uploaded and no game content is downloaded.

---

Use dumps of games you own. Report anything that will not install or launch — the verdict text
(`crashed (0xC0000409 …)`) is exactly what makes it fixable.
